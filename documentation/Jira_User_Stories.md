# Jira-ready user stories

**Epic 1 — Portfolio Visibility**
- US-01: As a banking executive, I want portfolio KPIs so I can assess exposure. Acceptance: customer, loan, principal and outstanding figures reconcile with SQL.
- US-02: As a risk analyst, I want delinquency and NPL rates so I can prioritize risk. Acceptance: rates follow documented DPD thresholds.

**Epic 2 — Branch & Customer Intelligence**
- US-03: As a branch manager, I want branch-level loan and transaction views so I can compare performance. Acceptance: branch filter updates applicable visuals.
- US-04: As an analyst, I want branch drill-through so I can investigate a selected branch. Acceptance: context is preserved on destination page and back navigation works.

**Epic 3 — Data Quality & Delivery**
- US-05: As a data analyst, I want validation checks so I can trust KPIs. Acceptance: ID uniqueness, orphan keys and negative balances are tested.
- US-06: As a reviewer, I want project documentation so I can reproduce the analysis. Acceptance: README, schema, queries, FRD, UAT and dictionary are included.
